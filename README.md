# Sistema de Pedidos - Pizzaria Provolones

Este programa em C simula um sistema básico de cadastro e gerenciamento de pedidos para uma pizzaria. 

---

## Funcionalidades

- Cadastro de até 5 pedidos com:
  - Código do pedido (1 a 10)
  - Sexo do cliente (m, f ou n)
  - Valor da pizza
  - Quantidade de pizzas
- Validação de entrada dos dados
- Consulta de pedidos por código
- Exibição de todos os pedidos cadastrados
- Estatísticas como:
  - Total de pizzas vendidas
  - Valor total vendido por clientes masculinos
  - Quantidade de pedidos acima de um valor informado
  - Média do valor dos pedidos
  - Código do pedido com maior quantidade vendida
  - Quantidade de mulheres que compraram
  - Total de itens vendidos por clientes que não declararam sexo
